* Первый итоговый проект - [Blogicum](https://github.com/Andrey-Dubov-25/blogicum)
  
Первый проект на Django для знакомства с фреймворком. Реализовал вёрстку через шаблоны, систему пользователей с разграничением прав доступа и оптимизированную работу с БД (filter, select_related, order_by).\
Настроил пагинацию (10 постов на странице) и локализацию админ‑зоны на русском языке.\
В результате добился быстрой загрузки страниц: 2,5–9 мс при 6–34 SQL‑запросах.\
  
***Предварительно изучены основы Python и Django (4 месяца).***
  
**Deadline** - *2 недели*. **Время выполнения** - *1,5 недели*.

* Третий итоговый проект - [API-YaMDb](https://github.com/Andrey-Dubov-25/api-yamdb)
  
Командой из 3-х разработчикой разработан API для сбора отзывов и рейтингов произведений на Django — проект стал практикой для закрепления навыков работы с API. Выступил в роли backend‑разработчика и тимлида команды из трёх человек.
Организовал процессы: настроил репозиторий на GitHub, внедрил канбан‑доску в Yonote,вёл ежедневные отчёты и проводил код‑ревью, общался с ревьюером. В части разработки реализовал модуль регистрации и аутентификации с кастомной моделью.\
Чёткие процессы (созвоны, связь в мессенджере) и навыки участников повысили прозрачность командной работы, а структурированный код упростил поддержку и развитие функционала.\
**Deadline** - *2 недели*. **Время выполнения** - *2 недели*.
