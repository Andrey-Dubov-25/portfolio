## Тестовые задания для прохождения собеседования
1) [GQB](https://github.com/Andrey-Dubov-25/guild_quest_board)
  
Разработал backend‑сервис для доски квестов фэнтези‑гильдии на Django + DRF с использованием PostgreSQL. Настроил запуск через Docker Compose, подготовил документацию API (Redoc), README с подробной инструкцией по развёртыванию и тесты для основных бизнес‑процессов. Проект готов к интеграции с фронтендом и масштабированию.

*В проекте используется следующий стек*
* Python
* Django
* DRF
* Pytest
* PostgreSQL
* Docker
* Redoc
  
**Deadline** - *1 неделя*. **Время выполнения** - *5 дней*.

## Учебные проекты (Яндекс.Практикум - python-разработчик)
*Проекты указаны по степени освоения [программы](https://practicum.yandex.ru/backend-developer/?from=catalog)*

* Первый итоговый проект - [Blogicum](https://github.com/Andrey-Dubov-25/blogicum)
  
Первый проект на Django для знакомства с фреймворком. Реализовал вёрстку через шаблоны, систему пользователей с разграничением прав доступа и оптимизированную работу с БД (filter, select_related, order_by).\
Настроил пагинацию (10 постов на странице) и локализацию админ‑зоны на русском языке.\
В результате добился быстрой загрузки страниц: 2,5–9 мс при 6–34 SQL‑запросах.\
  
***Предварительно изучены основы Python и Django (4 месяца).***
  
**Deadline** - *2 недели*. **Время выполнения** - *1,5 недели*.

* Второй итоговый проект - тестирование.\
  * [Ya_Note](https://github.com/Andrey-Dubov-25/ya_note) - на unittest
  * [Ya_News](https://github.com/Andrey-Dubov-25/ya_news) - на pytest
  
Освоил pytest и unittest: покрыл тестами основной функционал двух готовых проектов.
Теперь при изменении кода сразу видно отклонения от ожидаемого поведения, а логика системы стала прозрачнее.\
**Deadline** - *2 недели*. **Время выполнения** - *1,5 недели*.

* Третий итоговый проект - [API-YaMDb](https://github.com/Andrey-Dubov-25/api-yamdb)
  
Командой из 3-х разработчикой разработан API для сбора отзывов и рейтингов произведений на Django — проект стал практикой для закрепления навыков работы с API. Выступил в роли backend‑разработчика и тимлида команды из трёх человек.
Организовал процессы: настроил репозиторий на GitHub, внедрил канбан‑доску в Yonote,вёл ежедневные отчёты и проводил код‑ревью, общался с ревьюером. В части разработки реализовал модуль регистрации и аутентификации с кастомной моделью.\
Чёткие процессы (созвоны, связь в мессенджере) и навыки участников повысили прозрачность командной работы, а структурированный код упростил поддержку и развитие функционала.\
**Deadline** - *2 недели*. **Время выполнения** - *2 недели*.

* Четвертый итоговый проект - [Foodgram](https://github.com/Andrey-Dubov-25/foodgram)
  
Финальный проект по Django - разработал API для взаимодействия с фронтендом.\
Спроектировал и реализовал backend с нуля: настроил маршрутизацию, модели данных и endpoints.\
В процессе отработал навыки работы с API в Django, освоил Docker для контейнеризации, Postman для тестирования эндпоинтов и CI/CD для автоматизации тестирования, сборки и деплоя.\
**Deadline** - *4 недели*. **Время выполнения** - *3 недели*.
  
* Пятый итоговый проект - [Ya-Cut](https://github.com/Andrey-Dubov-25/foodgram)
  
Разработал Flask‑приложение с асинхронным взаимодействием с внешним API — закрепил навыки работы с асинхронностью в Python и оптимизировать обработку параллельных запросов.\
